# Fake Headline Generator

My first Python project — a simple random fake headline generator built with Python.

## 📌 About

This program generates random headlines by combining a subject, an exam, and a place.

Example:

> Python Midterm Scheduled in Library

## ⚙️ Features

- Generates random subjects
- Generates random exams
- Generates random places
- Creates a random headline
- Allows the user to generate multiple headlines
- Type `exit` to quit the program

## 🧠 Concepts Used

- Variables
- Lists
- `random` module
- `random.choice()`
- `while` loop
- `if` condition
- `input()`
- `.lower()`
- `f-strings`
- `break`

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
